# 💸 Tip Calculator

A modern, responsive Tip Calculator built with **HTML, CSS, and JavaScript**. It helps users quickly calculate tips and split the bill with ease.

## ✨ Features

- 🧾 Calculate tips based on the bill amount
- 🎯 Choose a tip percentage using preset buttons
- 💰 Calculate the total amount, including the tip
- 📊 Display the tip amount and total bill
- 🎨 Modern UI with gradients, glowing effects, and a dark theme
- 📱 Responsive design for desktop and mobile devices
- ⚡ Instant calculations with JavaScript
- ✅ Input validation for a better user experience
- 🌟 Custom SVG favicon

## 🛠️ Built With

- **HTML5** — Project structure
- **CSS3** — Styling, animations, and responsive layout
- **JavaScript** — Calculation logic and interactivity
- **SVG** — Custom favicon
